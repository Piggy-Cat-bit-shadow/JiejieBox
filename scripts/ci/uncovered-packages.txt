# Packages that have tests and are executed by no workflow.
#
# This file is a RATCHET, not an approval list. `scripts/ci/check-package-execution.py` fails when a
# package with tests appears that is not listed here, so a suite can no longer become silent by
# accident. Removing a line is the desired direction: it means a workflow now runs that package, and
# the script reports it as "no longer a gap" so the line gets pruned.
#
# Measured at the 0.1.53 release round: 35 of 109 packages with tests had no push-time runner. Three
# defects in the 2026-11 audit were found by RUNNING suites in this set (`e2e`, `protocol/*`,
# `service/oomkiller` - the last one has since been mounted), which is why the gate exists.
#
# The categories below say WHAT would mount each group, so the next round can act on them instead of
# re-deriving the question. A line is not a judgement that its tests are worthless.
