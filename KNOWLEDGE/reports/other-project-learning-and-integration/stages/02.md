## 实际改动

### G06 快速失败的创建速率与退避（新）

`common/resourceguard/rate.go`：

- `Guard` 新增 fast-fail 窗口：同一 seam 连续 `RateLimitAfter`（默认 4）次、每次 `< FastFailWindow`
  （默认 250ms）的失败才开窗；成功清零并重置退避级别。
- 退避 `RateLimitBase`（100ms）→ 指数 → `RateLimitMax`（2s），每窗口 ±20% 抖动；普通类别等待窗口
  （可取消、有预算），交互类别豁免；窗口长于调用方剩余预算时返回 `ErrRateLimited`。
- `Guard.ObserveOutcome(started, err)` 是唯一反馈入口；`IsLocalRejection` 明确本地拒绝集合。
- 热路径：无窗口时只做一次原子读（`rateUntil`），A/B 基准未测到回归（见 `EVIDENCE.md` E16）。
- 观测：`GuardStats.Rate` + `resourceGuard` metadata 的 `rate*` 字段。

接线：`protocol/anytls/admission.go`、`common/tls/client.go`、`protocol/mieru/dialer.go` 在真实创建
返回后回报结果；Mieru 还把拒绝错误写入 `dialObservation`。

### G05 Mieru underlay 真实准入

- `transportSpec` 携带 `resourceguard.FromContext(ctx)`；`newServerDialer` 增加 guard 参数。
- `serverDialer.DialContext` / `ListenPacket` 在 SDK 的 `newUnderlay` 接点取许可、按真实结果回报；
  `HeldPermit` 只标记本 seam 准入的 dial，防嵌套重复领取；Mieru 的 Mux/session 在其上，未覆盖
  部分在 `CONTRACTS.md` 注明。
- `protocol/mieru/admission_test.go` 证明：并发上限在 socket 处成立、标记传入真实 dialer、
  Mieru 的 fallback 分类把预算拒绝归为 Local。

### G03 TLS/AnyTLS 许可生命周期审计

- 审计 `HeldPermit` 的作用域：AnyTLS 客户端不保存 dial ctx（`sing-anytls` 的 session 只保存服务端
  `serviceContext`），TLS 的 `dialContext` 也不把 ctx 存进返回连接；标记只随单次 dial context。
- 新增 `common/tls/marker_scope_test.go`、`protocol/anytls/marker_scope_test.go`：调用方 ctx 不残留
  标记、第二次 dial 重新领取、嵌套 handshake 只领一份。
- QUIC 共享 offer（Hysteria2/TUIC/Hysteria）需要 `sing-quic` 内部 hook + fork pin + `source-lock`
  重建，且 TUIC 异步认证/0-RTT 的完成语义无法在本环境验证 → `NOT_ADOPTED_WITH_EVIDENCE`，
  见 `explorations/quic-shared-offer-admission-2026-11-08.md`。

### G02 本地资源错误分类与三账协作

- `resourceguard.IsLocalRejection` 覆盖 `ErrQueueFull`/`ErrWaitTimeout`/`ErrRateLimited`/
  `context.Canceled`/`context.DeadlineExceeded`。
- Mieru `classifyDialError` 在文本被 SDK 扁平化后，靠 `dialObservation` 保存的类型化错误恢复为
  `dialLocalFailure`，不切换传输、不判节点死亡（测试见上）。
- 公平/预留/老化/队列长度/等待预算沿用既有实现并在 `rate_test.go`/既有 gate 测试中复核；
  `CONTRACTS.md` §1.1 的三账顺序 02 未修改。

### G04 Cronet 原生连接

- 引擎与原生连接在 `cronet-go` 内；29 个 native 模块 `controlled`，本仓无 Chromium 工具链，
  且没有原生连接创建回调。不把 `Start` gate 冒充 native 覆盖，也不加 per-stream 伪 gate。
- 结论 `BLOCKED_EXTERNAL`，边界与重开条件见 `explorations/cronet-native-creation-coverage-2026-11-08.md`。
