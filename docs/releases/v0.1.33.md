# v0.1.33

与 satelite-one v0.1.33 配套发布，统一内核版本标识，沿用 v0.1.32 的协议、路由与配置行为。

## 版本与发布

- 内核版本更新至 0.1.33，无新增运行时代码或配置字段。
- 提供 Windows、Linux amd64、macOS arm64 命令行核心，Android arm64 AAR、Apple Libbox 及 Windows 客户端安装包。
- 附件提供 `SHA256SUMS`，用于核对下载文件。
