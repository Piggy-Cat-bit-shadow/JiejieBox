# v0.1.33：配套发布、版本对齐与继承能力说明

发布日期：2026-10-28。发布提交：`a0bbf666dec8693450c0e8363ed42db3294ac64a`。本说明根据版本标签、Git 差异和已发布附件补写，保留该版本真实的历史边界。

## 这版实际改变了什么

v0.1.33 是与 satelite-one v0.1.33 配套的核心版本。相对前一个核心标签 v0.1.32，只有 **1 个提交、1 个文件、1 行新增／1 行删除**：`release/JIEJIE_VERSION` 从 0.1.32 调整为 0.1.33。没有新增运行时协议代码或另做一轮性能重构。

这个版本完成的是**产品版本身份对齐和成套交付**：使用新的核心版本标识，便于与对应客户端版本、构建记录及下载附件一起识别。对维护者来说，它是可定位、可复查的发布点；对用户来说，应按平台选择这一版本的包，而不是从文件大小推断多出了一项协议功能。

## 它继承了哪些已经完成的工作

从更早版本升级的用户仍会获得此前积累的能力，尤其是 v0.1.31 的集中修复与 v0.1.32 的 endpoint/TUN 接线：

- **endpoint 的本地流量进入 TUN 处理。** v0.1.32 已将相关流量转入 TUN 栈并共享日志上下文；v0.1.33 保留这项行为。
- **网络变化与 TUN 重置交接。** 继承接口更新、启动交接窗口、DNS 劫持及关闭边界修复。
- **代理组保留完整候选列表。** selector、URLTest 与 loadbalance 将候选地址及策略传递到成员，改善首个地址黑洞消耗全部超时、另一地址族无法尝试的问题。
- **协议配置与 TLS 边界检查。** 保留 Naive 不支持选项的明确拒绝、uTLS/ECH 组合校验，以及 TUIC/HTTP3 包大小描述与实现对齐等修复。
- **FakeIP、嗅探、复制与释放责任。** 延续地址处理、分片 QUIC、连接关闭、kTLS 与零拷贝路径的回归保护。
- **Apple 客户端 pin。** 沿用前版固定的 Apple 客户端与其 TUN MTU 相关改动；本标签没有进一步更新客户端 gitlink。

上述内容说明这一发布点包含什么，不表示它们在 v0.1.33 首次实现，也不把历史基准变成本版重新测量的成绩。详细开发过程请参照 [v0.1.31 与 v0.1.32 日志](https://github.com/Piggy-Cat-bit-shadow/JiejieBox/blob/testing/CHANGELOG.md)。
